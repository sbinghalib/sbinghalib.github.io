# Typography

Binghalib brand guidelines for AI agents · https://sbinghalib.github.io/binghalib/agents/typography.md · Updated 2026-10-19
Use when: Setting any text: Inter Tight for headings, Inter for body and UI, weights, sizes, line heights. Why Bauhaus is never live text.
Rules that always apply: https://sbinghalib.github.io/binghalib/AGENTS.md

## Faces
- **Inter Tight** (SIL OFL 1.1, variable 100–900) for H1–H6 and display text. Files: `/assets/fonts/InterTight-Variable-latin.woff2` and `InterTight-Variable-latin-ext.woff2`. Licence: `/assets/fonts/OFL-InterTight.txt`.
- **Inter** (SIL OFL 1.1, variable 100–900) for body copy, UI labels, tables and captions. Files: `/assets/fonts/Inter-Variable-latin.woff2` and `Inter-Variable-latin-ext.woff2`. Licence: `/assets/fonts/OFL-Inter.txt`.
- **Bauhaus**: the logo typeface only. The wordmark is outlined artwork, and the Group Profile embeds Bauhaus-Bold only for the "ENTERPRISES" descriptor. It is a commercial face (ITC Bauhaus; cut and licence TBC) and is not supplied as a webfont. Never set text in it.
- Fallback: Poppins (OFL), for existing print templates.
- Arabic: Tajawal as a placeholder until the Arabic face is confirmed (TBC).

## Scale
- Display: Inter Tight 700, 58/1.05, tracking −2.5%
- H2: Inter Tight 700, 40/1.1, tracking −2%
- H3: Inter Tight 600, 22/1.3
- Body: Inter 400, 16/1.6
- Label: Inter 600, caps, tracking +14%
- Avoid weights below 300 on dark backgrounds.
